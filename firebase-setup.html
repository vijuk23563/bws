1

Open the configured Firebase project

Sign in at console.firebase.google.com and open project balaji-shop-1cd6f.

This website is already configured for that project. Do not create a second project or replace the existing web app config.

2

Create the admin sign-in

In Firebase Console, open Authentication → Sign-in method and enable Email/Password and Phone. Create the owner's admin user yourself; this website has no public sign-up. Set the SMS region policy for the countries you serve.

In Firestore, create admins/{UID}, replacing {UID} with that user's Authentication UID. Set the field role to the string admin.

The admin portal checks this role on every sign-in. Do not share the Firebase console account or add role documents for customers.

3

Confirm the database rules

The repository includes firestore.rules. Customers can submit valid bookings and design requests, but only an authenticated admin can read or manage them.

Create Firestore in production mode if needed. Enable Firebase Storage for gallery images. Deploy both checked-in rulesets before accepting live bookings. Never use open test-mode rules for a public website.

4

Configure Hosting and authorized domains

Firebase Hosting is configured in firebase.json. Add the deployed website domain under Authentication → Settings → Authorized domains.

⚠️

Do not deploy until the admin user and admins/{UID} role document are created. Firestore rules intentionally deny admin reads until then.

5

Deploy the website and rules

Install Firebase CLI, sign in, then run firebase deploy --only firestore:rules,storage,hosting from the website folder.

See DEPLOYMENT.md for the complete checklist, including App Check and post-deployment verification.

❓ Frequently Asked Questions

Is Firebase free?

Yes! Firebase's free tier (Spark plan) allows 50,000 document reads and 20,000 writes per day — more than enough for a booking website.

What if I haven't set up Firebase yet?

The website still works! Bookings save locally (in the browser). Once you set up Firebase, all new bookings go online automatically.

Can I access bookings from my phone?

Deploy with Firebase Hosting using the repository's Firebase CLI configuration, then sign in to the admin portal from any device.

How do I get notified of new bookings?

Currently via WhatsApp (customers send booking via WhatsApp button). For email notifications, you can add Firebase Cloud Functions later — ask Kiro to set that up.
